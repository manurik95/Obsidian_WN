Verben **Typen**:
### a) **Ru-Verben (一段, ichidan)**
Enden auf **-eru** oder **-iru**
- 食べ**る** (_taberu_) = essen
- 見**る** (_miru_) = sehen

**nai-Form**
 - 食べる → 食べ**ない** (_tabenai_) = nicht essen
 - 見る → 見**ない** (minai) = nicht sehen

**masu-Form**
- 食べる → 食べ**ます**
- 見る → 見**ます**

**masen-Verneinung**
- 食べます → 食べ**ません** (_tabemasen_)
- 行きます → 行き**ません** (_ikimasen_)


### b) **U-Verben (五段, godan)**
Enden mit **u**, aber ohne eru und iru
-  行く (_iku_) = gehen
- 話す (_hanasu_) = sprechen
- 読む (_yomu_) = lesen

Verneinung: **a + ない**
- 行く → 行**かない** (_ikanai_) = nicht gehen
- 話す → 話**さない** (_hanasanai_) = nicht sprechen

Bildung: letzte Silbe (u) →**i** + **ます**
- 行く → 行**きます**
- 話す → 話**します**
- 読む → 読**みます**

Verneinung-masu: (u) → **ません**
 行く → 行**きません**
 話す → 話**しません**
 読む → 読**みません**


### c) **Unregelmäßig (nur 2!)**
- する (_suru_) = machen → します (_shimasu_)
- 来る (_kuru_) = kommen → 来ます (_kimasu_)

Verneinung **masu**:
- しません shimasen
- 来ません kimasen 

Verneinung **nai**:
- しない (_shinai_) = nicht machen
- 来**ない (_konai_)** = nicht kommen
